# System-Bank

## A console System bank can Add/Edit client and users, make transaction between client in system


system back include:
  - Login page before enter to system
  - Menu to show options in system
  - options to add, update, delete, show client
  - options to add, update, delete, show user (Admin)
  - transaction option
    - Withdraw
    - Deposit
    - Show money in account
  - Permassion for each user
  - Show who enter in system (Who, when, email and password)

Client, user and all data save in file
password save with simple decode for security
